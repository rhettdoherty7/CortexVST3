# Fonts

All three families are under the SIL Open Font License 1.1 (OFL.txt). They are embedded in the plugin
binary, which the license allows, and are not sold separately. They are the same files Interlock ships,
so the two products share one typographic voice.

| File | Family | Use | Source |
|---|---|---|---|
| InstrumentSans-Regular.ttf, InstrumentSans-SemiBold.ttf | Instrument Sans, © The Instrument Sans Project Authors | interface text | Fontsource (latin subset) |
| JetBrainsMono-Regular.ttf, JetBrainsMono-SemiBold.ttf | JetBrains Mono, © The JetBrains Mono Project Authors | numbers, readouts | Fontsource (latin subset) |
| Unbounded-Bold.ttf | Unbounded, © The Unbounded Project Authors | the CORTEX wordmark | Fontsource (latin subset) |
